# Security

MPPKit parses files that come from other people, so a crash, hang or memory
blow-up on a malformed `.mpp` is a security problem.

Please report it privately through
[GitHub's private vulnerability reporting](https://github.com/hpetersen/MPPKit/security/advisories/new)
or to hello@mppstudio.com, not as a public issue. Include the smallest file
that shows it, if it contains no private data. You will get an answer within a
week.

Fixes are released for the latest version only.
